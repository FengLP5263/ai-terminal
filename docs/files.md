# 项目文件

简体中文 | [English](files.en.md)

点击终端顶部的“项目文件”图标，打开右侧文件树。右侧“文件 / Git”切换页共用同一面板，可调整宽度或收起。

文件夹按需展开并优先排列。点击文件，在主区域查看只读内容；文件树持续标记当前文件，路径悬停可查看完整位置。顶部刷新按钮更新当前面板，文件页还支持全部收起。关闭文件视图后回到原终端，原进程和后台输出保持连接。

## 项目与更新

有可用 Git 仓库信息时使用仓库根目录，否则使用当前会话的工作目录；普通目录无需安装 Git。切换项目时清除旧项目视图和过期查询结果。同一会话在仓库内切换子目录时保留项目根目录。

目录首次打开或展开时读取，已载入内容在当前视图内缓存。手动刷新或窗口重新获得焦点时按需更新，不定时扫描项目；刷新期间保留已有目录内容。文件仅在点击或刷新时读取，不执行脚本、加载插件或编辑内容。

## 内容与边界

- 支持 UTF-8（可带 BOM）和带 BOM 的 UTF-16 LE／BE，保留正常中文与 emoji；无效编码明确提示，不猜测修复原文。
- 共用 Git 文件视图的语法高亮、缩进线与原生彩色 emoji，普通文件使用单列行号；未知类型显示普通文本。
- 单文件预览上限 2 MiB。最多显示 20,000 行，每行 4,000 个字符，超过展示上限明确提示。
- 每级目录最多读取 1,000 项，缓存最多 64 个已展开目录，最多展示 20,000 个展开项及 32 层。收起文件夹会释放其子树缓存。
- 二进制、空文件、文件删除、访问失败和超限都有明确状态。链接及 Windows junction 显示为链接，不自动跟随或递归展开。

图标来自已有的微软 Codicons 原始字体，类型图标与 Git 共用；字体、字号及缩放继承应用设置。只保存 `ui.project_files_open` 面板偏好，不保存文件内容、目录快照或最近打开文件。旧配置默认关闭文件面板，保留原有 Git 偏好与会话目录。
