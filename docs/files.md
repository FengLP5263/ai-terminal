# 项目文件

简体中文 | [English](files.en.md)

点击终端顶部“文件夹图标＋项目名称”入口，打开右侧文件树；长名称省略，悬停可查看完整根目录路径。右侧“文件 / Git”切换页共用同一面板，可调整宽度或收起。

文件夹按需展开并优先排列。点击文件，在主区域查看只读内容；文件树持续标记当前文件，路径悬停可查看完整位置。顶部刷新按钮更新当前面板，文件页还支持全部收起。关闭文件视图后回到原终端，原进程和后台输出保持连接。

每个会话在本次运行中保留各自打开的文件、分页、滚动位置、Markdown 查看模式和图片缩放。切回时重新读取原文件，切走时释放正文和纹理。手动关闭预览、关闭会话或退出后清除该记录。

在文件页顶部输入文件名或相对路径即可搜索，不区分大小写。结果包括未展开目录和被 Git 忽略的项目文件。点击结果打开只读预览，右键可复制完整路径，清空搜索返回文件树。大项目最多显示 200 条结果，显示部分结果时可输入更具体的目录路径。

## 项目与更新

有可用 Git 仓库信息时使用仓库根目录，否则使用当前会话的工作目录；普通目录无需安装 Git。切换项目时清除旧项目视图和过期查询结果。同一会话在仓库内切换子目录时保留项目根目录。

目录首次打开或展开时读取，已载入内容在当前视图内缓存。手动刷新或窗口重新获得焦点时按需更新，不定时扫描项目；刷新期间保留已有目录内容。文件仅在点击或刷新时读取，不执行脚本、加载插件或编辑内容。

## 内容与边界

- 支持 UTF-8（可带 BOM）和带 BOM 的 UTF-16 LE／BE，保留正常中文与 emoji；无效编码明确提示，不猜测修复原文。
- 共用 Git 文件视图的语法高亮、缩进线与原生彩色 emoji，普通文件使用单列行号；未知类型显示普通文本。
- 大文本按页读取，每页最多 2 MiB／20,000 行；长行按 4,000 字符连续显示，不省略后续内容。支持上一页、下一页和回到开头；翻页期间文件发生变化会提示重新加载。
- PNG、JPEG、GIF、WebP、BMP、ICO、TIFF 和 SVG 在主区域水平、垂直居中预览，支持适应窗口、原尺寸和缩放，透明图片显示棋盘底色。动画仅预览首帧；超过 4,096 像素的图片缩采样预览。图片文件最多 32 MiB，栅格原图最多 32 百万像素且单边不超过 16,384 像素；SVG 最多 4 MiB，不加载外部图片资源。
- Markdown 默认渲染标题、列表、表格、引用及带语法配色的代码块，可切回源码。预览限宽居中，一级／二级标题带分隔线；表格按列换行，宽表格单独横向滚动。支持常见内嵌 HTML 的本地 `<img>`（保留 `width`／`height`）、`<div align="center">`、链接及换行；不运行 HTML 脚本、样式或嵌入页面。每页最多 256 KiB／2,000 行，复杂结构回退到源码；分页可能打断跨页结构。同地址、同尺寸的 HTML 插图共享解码与纹理资源，不重复占用图片预算。 项目内图片最多 16 张、单边缩至 2,048 像素、合计 16 百万像素。远程图片不自动联网；项目内文件链接使用相同只读查看器，网页／邮件链接仅在点击时交给系统。Word、Excel、PowerPoint 等文档不预览。
- 每级目录最多读取 1,000 项，缓存最多 64 个已展开目录，最多展示 20,000 个展开项及 32 层。收起文件夹会释放其子树缓存。
- 二进制、空文件、文件删除、访问失败和超限都有明确状态。链接及 Windows junction 显示为链接，不自动跟随或递归展开。

目录和操作图标来自微软 Codicons，类型图标与 Git 共用 Tabler SVG；字体、字号及缩放继承应用设置。右侧文件／Git 面板的收起、展开和页签按会话保存，不保存文件内容、目录快照或最近打开文件。旧全局偏好只迁移到原活动会话；其他会话默认收起。

右侧不重复显示根目录名称，搜索框位于页签与文件列表之间。全部收起、刷新和关闭在同一行。

文件类型图标采用内嵌 Tabler SVG（MIT），区分 Python、HTML、Rust、JS/TS、React、Vue、CSS、脚本、媒体和文档等。常见项目文件名优先于扩展名；未知类型使用普通文件或二进制回退。不读取文件正文来判断类型，文件树、Git 更改／提交列表及只读标题共用映射；目录和操作按钮继续使用 Codicons。

Git 忽略的文件及文件夹使用灰色名称和图标，悬停显示“已被 Git 忽略”，仍可展开与只读查看。分类由本机 Git 在目录加载／刷新时批量查询，遵循嵌套规则、例外规则、仓库 exclude 与全局忽略；已跟踪文件保持普通显示。Git 不可用、查询失败或普通目录无法确认时保留普通样式，不自行猜测，也不新增周期扫描。

音视频预览使用 Windows Media Foundation 原生引擎，音频播放器在内容区居中限宽，视频居中显示，播放、进度和音量控件叠在画面底部，细进度条单独一行。播放时指针闲置约 2.5 秒后，控件用 280 毫秒淡出，移动到画面上即可显示，暂停和操作控件时保持可见。提供标准播放／暂停、当前与总时长、可拖动进度条、静音和音量；取消静音恢复上次音量，播放结束后可点击播放重新开始。窄窗口会将进度条换到下一行，保持操作可用。识别 MP4/M4V/MOV/WebM/MKV/AVI/WMV/MPEG 及 MP3/WAV/FLAC/OGG/Opus/M4A/AAC/WMA/AIFF，能否解码取决于已安装的系统解码器；不支持或损坏时显示播放错误。不引入浏览器运行时或捆绑解码器包。引擎按需读取媒体，不把整份文件放入文本缓冲区，不受 2 MiB 文本分页限制。打开时暂停。切走时释放播放器和帧纹理；切回该会话时恢复进度和音量，保持暂停以便手动继续。切换文件或项目、关闭预览或退出会清除原进度。后台终端继续运行。播放列表及远程 URL 文件不作为媒体播放。视频预览帧单边最多 1,920 像素、最多 30 帧／秒；超过 16,384 像素单边或 64 百万像素的原视频拒绝预览。
