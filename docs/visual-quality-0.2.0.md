# 0.2.0 终端显示与会话面板

简体中文 | [English](visual-quality-0.2.0.en.md)

本轮针对用户提供的同一 Claude 会话与 Warp 截图差异，以及 Ctrl＋滚轮缩放需求。

## 行为

- 终端背景为 RGB(0,0,0)，侧栏和选择态改用中性灰；默认字号从 15 调整为 14。
- Hack 四种真实字形保留，字号、字形原点、网格和基线统一对齐物理像素。
  使用轻量 hinting 和线性度量；行高依据混合字形墨迹边界与 1.2 倍字号计算，避免 CJK 行框撑大所有行。
- 标题栏高度固定，状态未连接提示改为圆点 tooltip，避免 hook 连接时突然改变终端高度。
  ConPTY 只在行列或字符尺寸变化时接收 resize，减少无效重排。
- 鼠标位于终端正文时，Ctrl＋滚轮缩放，范围 8–32。普通滚轮继续滚动历史。
  标题栏百分比按钮恢复 14；缩放不会重新启动终端，IME 焦点保持。
- 会话卡片支持鼠标拖动排序；悬停铅笔或右键编辑名称；标题栏 ‹/› 收起、展开。
  收起后仍可通过 Agent 头像切换会话；拖动面板右边缘调整宽度。
- 头像与生命周期提示分别显示；工作、等待、未读完成沿用原事件 reducer。
  排序只移动 Session 所有权，终端、PID、Job Object、resume ID 和活跃 UUID 不变。
- sessions.json 新增可选 ui 对象，旧文件通过默认值兼容，保留原有损坏文件保护。
  频繁字号／宽度修改延迟保存，退出立即保存。

## 验证方法

新增鼠标事件回归覆盖卡片选择、编辑与拖放的区分、跨卡片排序和收起后的选择；
新增真实 ConPTY + IME 回归确认缩放过程中 PID 不变、组合输入不被中断、偏好可回读。
字体用 100/125/150/200% DPI 和 8/14/15.5/24/32 字号验证物理像素与基线。

治理、fmt、Clippy -D warnings、42 项 Rust、3 项 Python 检查通过。
12000 行隐藏 PTY 用例在并行优化构建时出现一次 15 秒超时，串行复验用时 12.84 秒通过；
没有放宽期限或移除断言。原生 UI 验收应与重型编译分开执行。

examples/workspace_probe.rs 使用本地 PowerShell ANSI 样例，捕获展开、Ctrl＋滚轮缩放、收起三个实际 GPU 画面；
终端样例必须就绪才采集，不能用空白启动画面通过验收。examples/terminal_probe.rs 在已信任目录
等待真实 Claude/Codex UI 后，仅注入未提交 IME/Text，不发送 Enter 或请求模型。

截图和制品的最终目录、结果及边界见下文。现有 Claude fullscreen 回退与系统物理输入法
全部组合的验收边界保留；本轮没有改 CLI 的全局设置。字体观感仍以用户实际使用验收为准。
