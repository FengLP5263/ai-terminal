# Documentation translation status

[简体中文](i18n-status.md) | English

Current and historical project-authored documentation, third-party provenance notices, and local vendor patch notes have Chinese and English versions. GitHub issue/PR templates are bilingual on the same page. Third-party licenses and original upstream texts remain unchanged; `CLAUDE.md` is a tool entry and has no separate copy.

This does not mean automation can prove semantic equivalence. Review both languages when changing content according to the [bilingual policy](i18n.en.md); missing pairs or language-switch links fail governance checks.
