# 双语文档规范

简体中文 | [English](i18n.en.md)

项目面向不同语言的贡献者，当前中文正文保留原路径，英文对应文件使用 `.en.md`，例如 `README.md` / `README.en.md`、`SKILL.md` / `SKILL.en.md`。两种语言应忠实表达相同的事实、命令、权限和验证边界；不依赖机器翻译的字面一致。页面顶部提供双向语言切换。AI 工具仍以原路径 `AGENTS.md`、`SKILL.md` 为入口；英文版供协作者阅读，不能改变工具识别机制。

新建或修改项目自有现行文档时，同一改动内更新两种语言及相对链接；命令、参数、路径、版本、哈希和许可证名称保持一致。验证规则由仓库治理脚本执行，检查配对文件及互链；自动检查不能证明翻译语义正确，仍需人工审阅。

双语审阅完成后，在仓库根目录执行 `python scripts/check_bilingual.py --record` 更新内容摘要，并与两种语言的变更一起提交。治理检查会检测配对、互链以及摘要变动；摘要仅用于提示变更，不能代替对翻译准确性的人工审阅。

第三方许可证、上游版权／原文及自动生成材料保留原样，不自行改写法律文本。GitHub Issue／PR 模板使用同页双语。`CLAUDE.md` 是指向 `AGENTS.md` 的工具入口，不另建文本副本。历史版本文档保留原路径和当时的证据，不改写为当前行为；翻译覆盖情况见[文档翻译状态](i18n-status.md)。本地 vendor 补丁说明提供双语，原始上游资料与许可证不改写。
