# 版本与发行规则

简体中文 | [English](versioning.en.md)

本项目从 0.5.0 起按 [SemVer 2.0.0](https://semver.org/lang/zh-CN/) 决定版本。版本级别依据上一个正式发行标签以来的全部变更；混合变更采用最高级别，不能只看最后一个修复提交。

| 变更范围 | 版本变化 | 示例 |
| --- | --- | --- |
| 兼容的问题修正、安全修复、既有行为的显示／性能修复，无新用户功能 | 修订号加一 | 0.5.0 → 0.5.1 |
| 向下兼容的新功能，包含同批修复 | 次版本加一，修订号归零 | 0.4.11 → 0.5.0 |
| 稳定公共契约的不兼容变更（1.0.0 起） | 主版本加一，次版本及修订号归零 | 1.2.3 → 2.0.0 |
| 正式版前的本地预览 | 目标版本追加 -preview.N | 0.5.0-preview.1 |

公共兼容范围包括文档承诺的用户功能、启动参数、会话／设置保存与恢复、外部 hook 元数据接口。普通视觉修正归修订级；本次首次加入 Git 工作区视图属于新功能，配色和标题栏修复一并包含在 0.5.0。

SemVer 将 0.y.z 视为初始开发阶段，公共 API 尚不承诺稳定。本项目在该阶段仍区分兼容新功能和修复；若有不兼容变更，至少提升次版本，并在发行说明明确列出迁移、备份和回退方案。1.0.0 用于建立稳定公共契约，之后不兼容变更提升主版本。开发阶段也不能通过清空会话或切换数据目录处理兼容问题。

发布前明确记录：上一个正式标签、完整范围、变更级别和目标版本。Cargo.toml、Cargo.lock、双语 CHANGELOG、安装器版本、制品名称和 app-v<version> 标签必须一致；通过现有治理、测试和包回读检查，从经审查的干净主线提交构建。GitHub Release 沿用同一条目，再附实际验证及附件摘要；具体权限和 PR 流程见 [Git 协作](../.agents/skills/ai-terminal-git-workflow/SKILL.md)。

已经公开的版本、标签和制品不覆盖或改名。发现问题用新版本修正。过去已发行版本与已交付的本地预览保留原始编号；本次本地 0.4.12-preview.N 的开发内容整理为正式 0.5.0，不发布 0.4.12 正式版。
