# 治理与初始化验收

## 采用前基线

2026-10-30，版本 0.1.2。独立 Git 已初始化但 develop 尚无提交；无远端、额外 worktree、标签或云发布配置。
生产源码、Cargo.lock、输入／DPI 回归、字体来源和许可证已存在；历史 36 项 Rust 测试通过。
用户本次授权项目治理与首次本地提交，不包含推送、标签、线上发布或新产品功能。

## 发现与处理

| 差距 | 本轮处理 |
| --- | --- |
| 协作规则只有概述 | 合并 AGENTS，明确权限、读图验收、源码边界和完成标准 |
| 缺少实际架构／数据／集成地图 | 增加 .agents/architecture 四份事实记录 |
| 工作流依赖会话和临时脚本 | 增加本地开发、测试、制品三项项目技能 |
| 无统一成对入口，平台支持模糊 | Windows/POSIX project 入口；不支持的原生动作明确失败 |
| 无可重复维护的 ZIP 交付 | package.py 构建、依赖／许可证清单、文件身份、ZIP 回读与篡改／路径穿越回归 |
| 忽略规则不完整 | 补运行数据、真实配置、私钥、数据库、压缩包及缓存排除 |
| 有本机文档路径与历史 Git 状态 | 改为相对路径／环境变量，历史记录明确时间范围 |
| 真实模型核查可误执行 | 显式 AllowModelRequest，默认 CI 不触发模型费用 |
| 脚本缺少帮助／退出边界 | 命令优先帮助、UTF-8 BOM、唯一输出目录、截图／回收校验与失败传播 |

## 范围保留

不移动或重命名生产源码，不改 src/、vendor/egui_term/src/、字体字节、UI、协议、数据格式和运行行为。
源码布局、原开发脚本及 .tools 本机工具链位置保留；不会清理用户正在运行的终端或修改其他仓库。
采用 stable + Cargo.lock，记录实际编译器，尚未承诺编译器精确版本／位级可复现。
依赖许可证自动清单有明确收集范围，不代替发行方式的完整法律审查。

## 本轮验证

实际结果在治理完成后补记。Windows 为验证平台；Git Bash 只代表 Windows 上的 shell 分支，
macOS/Linux 运行未验证。真实模型核查仅测试帮助与显式拒绝，沿用历史联调证据，不在治理中重复计费。
未建立远端，因此云 CI、PR 保护、签名、自动更新和远端发行均不宣称完成。
