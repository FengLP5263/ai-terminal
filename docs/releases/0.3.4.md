# ai-terminal 0.3.4

简体中文 | [English](0.3.4.en.md)

Windows x64 预览版。本次更新集中改进命令行会话管理、滚动体验和界面细节。

- **终端即开即用**：默认 PowerShell，＋菜单支持 PowerShell、CMD 和 Git Bash；新会话沿用当前／最近的工作目录，支持终端内 cd 后更新。
- **自动识别 Agent**：在受管终端输入 codex 或 claude 后显示对应头像，退出后恢复 Shell 图标；任务状态仍来自生命周期通知。
- **会话整理**：细分隔线、统一图标与中文标题；右键可设置 7 种颜色，当前会话更亮，颜色随会话保存。
- **滚轮修复**：普通滚轮查看终端输出，不再模拟上下方向键切换输入历史；Codex 以保留滚动历史的内联模式启动。Ctrl＋滚轮仍缩放整个窗口。
- **表情名称**：侧栏、标题和重命名框支持 Windows 彩色表情、肤色和组合序列，保留标准选择、复制与粘贴。
- **程序图标**：采用 B「会话叠窗」，内嵌 16–256 像素的 10 档 Windows 图标。
- **CLI 查找兼容性**：查找公开 exe/cmd/bat 入口，支持用户／系统 PATH 和常见安装目录，不依赖开发设备的固定路径。

## 下载和使用

下载 Windows x64 ZIP，完整解压后运行 ai-terminal.exe。ai-terminal.exe 与 ai-terminal-hook.exe 必须放在同一目录；无需 Rust、Python 或 Electron。先在本机安装并配置要使用的 Codex／Claude CLI。

右键会话 → 会话颜色可更改配色。升级后在新窗口中启动 Codex，才会使用新的滚动模式。

## 兼容性与验证边界

旧 Codex／Claude 标签通过 PowerShell 打开，名称、目录与历史 ID 保留，不会自动执行 Agent；恢复 AI 对话请使用对应 CLI 的恢复命令。程序保存会话元数据，不保存终端正文，不承诺恢复上次运行进程。

本版本已在 Windows 原生环境验证；macOS/Linux GUI 尚未支持。物理输入法的全部组合、图片粘贴、长期高并发和 Claude fullscreen renderer 仍需进一步验收。新表情的可用性取决于 Windows 字体版本。

常规验证不调用模型 API；真实终端、合成生命周期和未提交文本的 TUI 核查分开记录。发行 ZIP 附带 manifest、文件哈希与许可证，校验和另附 SHA256SUMS。
