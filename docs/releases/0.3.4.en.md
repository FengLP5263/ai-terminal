# ai-terminal 0.3.4

[简体中文](0.3.4.md) | English

Windows x64 preview. This release improved shell-session management, scrolling, and interface details.

- **Ready-to-use shells:** PowerShell by default; plus menu offers PowerShell, CMD and Git Bash. New sessions inherit the current/recent directory and track shell `cd` changes.
- **Agent identification:** `codex` or `claude` in a managed terminal switches to the Agent avatar, returning to the shell icon on exit. Task status still uses lifecycle notifications.
- **Session organization:** Thin separators, consistent icons/Chinese title, seven context-menu colors, brighter active row, and persisted colors.
- **Scrolling:** Wheel views terminal output rather than simulating history-arrow keys; this historical version launched Codex in inline mode to retain history (superseded in 0.3.7). Ctrl+wheel scales the window.
- **Emoji names:** Sidebar, title, and rename support Windows color emoji, skin tones and composed sequences, with normal selection/copy/paste.
- **Application icon:** B “stacked sessions,” embedded in ten 16–256-pixel Windows sizes.
- **CLI discovery:** Public exe/cmd/bat launchers, user/system PATH and common installation paths, without a fixed developer machine path.

## Download and use

Download and fully extract the Windows x64 ZIP, then run `ai-terminal.exe` with `ai-terminal-hook.exe` in the same directory. Rust, Python and Electron are not needed to run it; install/configure Codex or Claude separately. Use session context menu → color. After upgrading, launch Codex in a new window for that version's scrolling behavior.

## Compatibility and validation limits

Legacy Codex/Claude tabs open via PowerShell, retaining name, directory and history ID without starting the Agent. Use the CLI's resume command to restore an AI conversation. The app stores session metadata, not terminal text, and does not promise to restore running processes.

This version was verified natively on Windows; macOS/Linux GUI was not supported. All physical IME combinations, image paste, long-term concurrency, and Claude fullscreen renderer still required acceptance; new emoji depend on Windows font versions. Standard validation made no model calls; real terminals, synthetic lifecycle and unsent TUI text were recorded separately. The ZIP included manifest, file hashes and licenses, with a separate SHA256SUMS file.
