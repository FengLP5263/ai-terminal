# 0.1.1 输入与显示修复

简体中文 | [English](input-display-0.1.1.en.md)

2026-10-30。用户反馈 0.1.0 输入和显示不可用。本轮先复现再修复，未添加新产品功能。

## 已复现的问题

旧代码每帧调用 request_focus，egui 会因此发出 should_interrupt_composition，
直接打断系统输入法的组合输入。新增回归在旧代码明确失败。
旧渲染只绘制基础字符，丢失组合附加字符；同一渲染回归也先失败。
缺少终端焦点锁、取整后的字符网格、真实光标形状以及框线/块状字形绘制。

## 修改

- 使用稳定终端控件 ID，仅在激活/点击/需要恢复时请求焦点；重绘不中断输入法。
- Tab、方向键和 Esc 交给终端；弹窗和菜单期间停止接收终端输入。
- 中文候选过程抑制原始候选按键；提交、取消与后续编辑分别处理。
- Ctrl+C 在有选区时复制；新建快捷键改为 Ctrl+Shift+N，保留 Ctrl+N 的终端语义。
- 网格宽度向上取整并考虑中文宽字形；先画背景再画字符；保留组合字符、隐藏属性和动态颜色。
- 使用 Alacritty 提供的光标位置与形状；常用框线、整块和象限字符按网格几何绘制，消除接缝。
