# 安装版与字体选择

简体中文 | [English](installation.en.md)

## 使用安装版

从对应发行附件选择 `*-setup-*.exe`，按向导安装到当前用户目录（默认 `%LOCALAPPDATA%/Programs/AI Terminal`）。安装无需管理员权限，开始菜单提供启动和卸载入口，桌面快捷方式可选。安装完成后的自动启动默认不勾选。免安装 ZIP 继续提供，完整解压后运行。

两种分发形式共用 `%LOCALAPPDATA%/ai-terminal` 的会话与设置。程序目录与数据目录分开；安装器不安装 Agent CLI、不更改 CLI 配置或系统字体。升级／卸载遇到文件占用时先停止操作，提示用户自行关闭对应程序，不自动结束任务。卸载只删除清单中的程序文件，保留会话、设置和额外用户文件；拒绝将非空的陌生目录、会话数据根目录或目录链接作为安装目标。

安装版在自己的目录保存 `.ai-terminal-installed` 标记，首次运行的桌面快捷方式交给安装向导管理；ZIP 保留原有首次启动行为。升级默认沿用已登记的安装目录，显式 `/D=` 参数优先。安装／卸载信息只写当前用户的 Windows 卸载注册表，不需要后台服务。

0.4.10 起同时提供安装版与免安装 ZIP。公开发行以 GitHub Release 实际附件为准；当前没有自动检查更新与代码签名。

## 终端字体

在设置 → 终端字体选择，全部会话即时生效并保存，不重启终端或 Agent。

| 字体 | 来源 | 说明 |
| --- | --- | --- |
| JetBrains Mono | 内置四种官方原始字形 | 默认，v2.304，SIL OFL 1.1 |
| Cascadia Mono | 内置四种原始字形 | 沿用 0.4.9 |
| Hack | 内置四种原始字形 | 沿用 0.4.8 |
| Consolas | Windows 已安装字体 | 缺失时禁用 |
| Courier New | Windows 已安装字体 | 缺失时禁用 |

中文继续使用系统 Microsoft YaHei UI，表情使用系统彩色 emoji。界面语言、会话名称与控件字体保持原样；此选项改变终端正文。系统字体不复制进程序或安装包。新工作区、缺少字体字段的旧设置及未知的未来字体 ID 使用 JetBrains Mono；已保存的字体选择保持不变，来自其他电脑的不可用字体安全回退默认。字体目录只检查已知文件一次，不扫描所有字体或逐帧读盘。

## 本地构建与验收

命令和固定 NSIS 工具链准备见 [脚本目录](../scripts/README.md)。`installer` 默认先构建经过回读校验的 ZIP，也可通过 `-Path` 选择已有 ZIP；脏预览必须显式 `-AllowDirty`。安装版另有 EXE 摘要、校验文件和 JSON 清单，记录 ZIP 源码身份、安装脚本与编译器身份。`verify-installer` 仅校验 EXE 摘要，不执行安装器，也不声称完成签名校验。

`-Acceptance` 构建独立注册表与快捷方式身份。`installer-smoke` 只接受这种包，在 `output/` 的唯一中文／空格路径测试首次安装、占用拒绝、升级、包内六 PTY smoke、卸载保留数据及清理自身注册表。用相同 `-AcceptanceId` 构建旧／新包，并通过 `-Previous` 验证真实版本升级。失败材料保留，不能把失败截图或未完成的卸载算作通过。
