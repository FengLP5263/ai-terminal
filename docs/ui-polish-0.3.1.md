# 0.3.1 界面细节优化

本地开发版，沿用「清爽工作台」的统一尺度、低装饰密度与可访问控件原则，保持紧凑的桌面终端布局。

## 调整范围

- `src/chrome.rs` 集中管理图标与桌面控件尺寸：操作图标 16、点击区 32；头像容器 32、内部标识 20（均为逻辑像素，随整体缩放）。
- 新建、面板展开／收起、编辑使用统一的 1.5 线宽矢量图标，提供可访问名称、提示、悬停／按下和键盘焦点反馈。
- Codex、Claude 与三个 Shell 的头像居中，Shell 图标改为同一画布上的矢量形状；现有品牌 PNG、字体及来源哈希保持一致。
- 对齐列表标题、辅助文字和状态标记；辅助文字采用 12，选中、悬停及状态标记底色保持一致。编辑区留出固定空间，长名称不覆盖操作按钮。
- 工具栏高度及缩放比例按钮与其他操作对齐。终端正文继续使用现有纯黑背景、Hack 字体和 Windows 原生文字绘制。

新建终端菜单、目录继承、Agent 识别、生命周期、会话保存与整体缩放沿用现有流程。
