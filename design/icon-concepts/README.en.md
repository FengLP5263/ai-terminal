# AI Terminal icon concepts

[简体中文](README.md) | English

Open `index.html` to compare four original vector concepts A–D, switch themes, inspect 16/24/32/64-pixel previews, and copy selection or feedback. The page has no external or network dependencies; choices remain in the local browser.

`a.svg`–`d.svg` are the individual sources. The user selected B “stacked sessions,” which became the application icon in 0.3.4; fixed exports are in `assets/branding`. The remaining candidates are retained for comparison. The project drew these graphics and licenses them under MIT.
